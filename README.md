# cumuli-core

Shared Python components of the Cumuli 4D Gaussian splatting stack: the 4D
interchange PLY reader and writer (format spec: `docs/sogst-format.md` in the
cumuli repo, CC-BY-4.0), the spacetime slice and gsplat renderer, the 4D
training dataset reader, and image-quality metrics.
